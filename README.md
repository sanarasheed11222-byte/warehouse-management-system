# Amazon Warehouse Store Management System (Frontend)

A fully responsive warehouse/inventory management admin panel built with HTML5, CSS3, and Bootstrap 5 — developed as a frontend internship assignment for U Devs.

## Live Pages
This is a static frontend-only project (no backend/database). All 17 required pages are included.

## Pages Included
- Login / Signup
- Dashboard (with widgets: Total Products, Orders, Pending Orders, Stock, Revenue, Profit, Loss, Wastage, Low Stock Alerts)
- Products List, Add Product, Edit Product
- Categories
- Suppliers
- Stock In / Stock Out
- Orders, Order Details
- Profit & Loss Report, Wastage Report
- User Profile
- Settings
- 404 Page

## Tech Stack
- HTML5
- CSS3 (custom theme on top of Bootstrap)
- Bootstrap 5
- Bootstrap Icons
- Vanilla JavaScript (form validation, sidebar toggle)

## Features
- Fully responsive layout (mobile, tablet, desktop)
- Dark sidebar navigation with active-state highlighting
- Reusable component patterns (cards, tables, modals, badges)
- Form validation on all CRUD forms (Products, Categories, Suppliers, Orders, Profile)
- Search bars, filters, and pagination on all list pages
- Breadcrumb navigation
- Static charts for Sales Overview and Profit Trend
